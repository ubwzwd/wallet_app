# 给 Claude Design 的设计提示词

用法：在 claude.ai/design 新建一个项目，把 **§1 背景** 整段作为第一条消息发过去；然后按 **§2 逐屏提示词** 一屏一屏地要；最后用 **§3 交付提示词** 让它把 token 和组件规格导出来，交回给 Claude Code。三个方向的首页对比小样已经在这里：https://claude.ai/code/artifact/a1994e12-ca46-4130-847d-a737e5c7a1ec ，可以截图或导出 PNG 一起贴给 Claude Design 当起点。

---

## 1. 背景（第一条消息，整段粘贴）

我在做一个家庭记账网页应用（之后会打包成 Android / iOS App），请为它做一套全新的视觉设计。下面是你需要的全部上下文，请先读完再开始。

**产品是什么**
- 亲友之间共用的记账本：一个人可以有多本账，每本账可以邀请家人一起记。
- 交易只有四种：支出、收入、退款、转账。退款可以关联到原来的支出；转账可以是账本内两个账户之间的（两条腿），也可以是和外部之间的（一条腿，只写"对方是谁"的文字）。
- 分类固定两级（一级必填、二级可选），一级分类带一句"归类判据"说明文字，要在选择器里显示。
- 账单导入：用户在自己的 ChatGPT / Claude 里用我们提供的 skill 把账单整理成标准文件，再上传到应用；应用校验后进入一个 review 表格，用户逐行确认、改分类、关联退款原单、配对转账，然后提交入账。应用本身不调用大模型。
- 首页：账户余额（各按账户币种）+ 折算成基准币种的合计、本月按分类的支出 / 收入、最近 12 个月趋势。
- 多币种：账户各有币种，账本有一个基准币种，涉及折算的地方要同时显示原币和折算值。

**用户和平台**
- 用户是我和家人朋友，不是公开产品；界面中文为主，需要英文版（i18n），文案请用中文写，英文之后翻。
- 响应式网页：窄屏 375 宽用底部 5 个 tab（首页、交易、记一笔（中央凸起）、导入、我的）；宽屏 ≥1024 用左侧导航 + 顶部账本切换。
- 导入 review 表格要在桌面上真正好用：粘性表头、行内编辑、键盘上下移动、批量操作；手机上退化成卡片流。
- 浅色和深色两套都要，都必须过 WCAG AA（正文 4.5:1，大字与图形 3:1）。

**硬性规则**
- 所有金额、日期、行号用等宽数字（tabular-nums），负数用真正的减号 U+2212，千分位分隔。
- 四种交易种类各有一个语义色：支出 / 收入 / 退款 / 转账，另配淡底版；语义色和主强调色分开。
- 图标用统一的线性图标集（20px 网格、一致描边），不用 emoji。
- 不要通用 SaaS 模板感：不要紫蓝渐变 hero、不要圆角卡片加左侧色条、不要把所有东西都做成卡片。
- 触控目标不小于 44×44。
- 组件在 React Native + react-native-web 上实现，所以不要依赖 CSS 伪元素、`backdrop-filter` 这类 Web 专属效果。

**视觉方向**
- 我有三个候选方向的首页小样（见附图）：A「账本纸张」——暖白纸底、墨色文字、发丝线分栏、标题衬线、数字等宽，红 / 绿 / 琥珀 / 灰蓝对应四种交易；B「静音仪表盘」——瑞士网格、灰阶层次、单一靛蓝强调，收支靠箭头方向；C「夜间记账台」——深色优先、琥珀强调、分类彩色圆点。
- 请先基于 **方向 A** 深化（这是我目前的倾向），同时吸收 B 的 8px 间距刻度和统一图标集。如果你认为某处 B 或 C 更合适，做出来给我看并说明理由。

**请按这个结构输出 token**（名字不要改，值由你定，浅色深色各一套）
- 颜色：`bg.canvas` / `bg.surface` / `bg.raised` / `bg.subtle` / `bg.hover` / `bg.selected`；`fg.primary` / `fg.secondary` / `fg.muted` / `fg.inverse`；`border.default` / `border.strong` / `border.focus`；`accent.solid` / `accent.fg` / `accent.subtle`；`kind.expense` / `kind.income` / `kind.refund` / `kind.transfer`（各配 `.subtle`）；`status.success` / `warning` / `danger` / `info`（各 `.fg` / `.bg`）；`flag.duplicate` / `flag.needs_review` / `flag.uncategorized`；`chart.series[0..7]`。
- 字号阶（px / 行高）：`text.display` 40/44、`text.title` 28/34、`text.heading` 20/28、`text.subheading` 16/24、`text.body` 14/20、`text.caption` 12/16、`text.micro` 11/14；数字用同档 + tabular-nums。可以微调数值，但保留这七档。
- 间距：4 的倍数，`space.1` = 4 到 `space.16` = 64。圆角：`radius.sm/md/lg/pill`。阴影：`shadow.none/raised/overlay`。
- 字体：最多三个字族（标题、正文、等宽数字），必须是 Google Fonts 上有的，并给出中文回退。

**组件清单**（每个都要有默认、悬停、按下、禁用、错误态）
Button（primary / secondary / ghost / danger，三档尺寸）、TextField、AmountField（等宽、千分位、币种内嵌）、DateField、Select / MultiSelect、CategoryPicker（两级级联，一级是"名称 + 一行判据"的两行选项）、SourcePicker（账户：名称 + 类型图标 + 币种 + 余额）、SegmentedControl、Card（flat / outlined / raised）、DataTable（review 表格底座）、Badge（含四种交易色与三种标记色）、Chip（筛选条件）、BottomTabBar（五项，中央凸起）、Sidebar + LedgerSwitcher、EmptyState、Toast、ConfirmDialog、Skeleton、Sheet（窄屏底部抽屉）、ProgressBar、StatTile、BarList / TrendChart。

**统一用这组示例数据**（所有屏幕保持一致）
- 账本：家庭账本（基准币种 CNY）；成员：我（owner）、老婆。
- 账户：招行储蓄卡 CNY 12,480.35；建行信用卡 CNY −3,215.00；DBS Multiplier SGD 4,120.80（折算 ¥24,576.75）。
- 净资产 ¥33,842.10；9 月支出 6,842.50、收入 18,000.00。
- 9 月分类：餐饮 2,140.00、居住 2,000.00、生活购物 1,205.50、交通 860.00、娱乐 420.00。
- 最近交易：瑞幸咖啡 −45.00（支出 · 餐饮 / 零食饮料）；9 月工资 +18,000.00（收入 · 工资 / 基本工资）；京东退款 +199.00（退款 · 消费购物）；还信用卡 3,000.00（转账 · 招行储蓄卡 → 建行信用卡）；Grab 打车 −S$12.40（支出 · 交通 / 打车，DBS）。

先不要画任何屏幕。第一步请给我：token 表（浅色 + 深色）、字体方案、图标风格样例、以及 Button / TextField / Badge / CategoryPicker 四个组件的各种状态。我确认后再进入屏幕。

## 2. 逐屏提示词（token 确认后，一屏一条）

每条都在开头加一句："沿用已确认的 token 和组件，示例数据不变。每屏给 375 宽和 1440 宽两个版本。"

1. **首页（有数据）**：账本切换器在顶部；净资产大数 + 本月支出 / 收入；账户列表（三个账户，外币账户显示原币和折算）；本月分类条形（5 条，可点进二级）；12 个月趋势；最近 5 笔交易（四种种类各至少一笔）。宽屏时左侧导航，内容区两列。
2. **交易列表 + 筛选栏展开**：筛选项：关键词、种类多选、账户多选、日期区间、一级 / 二级分类、金额区间，已选条件显示为可关闭的 Chip；列表里包含四种种类各一行、一行跨币种（显示原币 + 折算）、一行单腿转账（显示"对方：工资卡"）；行上显示种类色、分类、商户、备注、金额。窄屏筛选放底部抽屉。
3. **导入 review 表格（桌面）**：列：勾选、行号、日期、金额、币种、种类、商户、备注、一级分类、二级分类、对手账户 / 对方、状态与标记。标记徽章四种：重复、退款候选、可配对转账、需核对；缺一级分类的行显示"待归类"，页面顶部有阻断条"还有 3 行待归类，补齐后才能提交"；底部批量操作栏：批量设分类、批量跳过、提交。窄屏版本是卡片流，每张卡可展开编辑。
4. **记一笔 — 支出**：四种种类的 Segmented 切换在顶部；金额输入（等宽、大号、币种内嵌）；账户；日期；分类选择器展开态——左列一级（名称 + 一行判据）、右列二级（第一项固定"不细分"）；商户；备注。
5. **记一笔 — 转账**：转出账户、转入账户（可选"不在应用里 → 填对方文字"）；两边金额与币种（同币种时只填一次，跨币种时展开两个金额）；子类型：普通 / 信用卡还款。给两张：两腿跨币种态、单腿对方文字态。
6. **记一笔 — 退款**：金额、账户、日期、分类；"关联原支出"入口打开一个选择器浮层：复用交易列表筛选（默认支出、同账户、最近 90 天），每条显示已退 / 可退金额。
7. **交易详情（两腿转账）**：两条腿并排显示，操作：编辑、拆开（变回两条单腿）、删除；另给一张单腿转账详情，操作里多一个"关联为转账对腿"。
8. **账户列表 + 账户表单**：列表显示名称、类型、币种、余额（原币 + 折算）、归档账户折叠在底部；表单：名称、类型（储蓄 / 信用卡 / 现金 / 其他）、币种、期初余额。
9. **导入 — 指南与上传**：三步说明（安装 skill → 在你的 ChatGPT / Claude 里整理账单 → 上传生成的文件）；skill 文本的复制 / 下载按钮；上传区（选目标账户 + 拖入文件 或 粘贴文本框）；校验失败态：按行号列出错误；版本过期态："你的 skill 版本是 2026-08-01，当前 2026-09-10，请更新后重传"。
10. **导入历史**：批次列表，两种状态：待提交（ready）、已提交（committed，可撤销）；撤销确认对话框显示条数与"会有 2 笔退款失去原单"的提示。
11. **账本设置**：成员列表（名称、角色、加入时间，owner 可移除）；"生成邀请码"按钮 → 显示 6 位码和 10 分钟倒计时；转让 owner、退出、删除账本（需输入账本名确认）；基准币种修改时的警告。
12. **账本列表 / 加入账本**：账本卡片（名称、成员数、基准币种）、新建；加入账本：6 位码输入框。
13. **个人设置**：显示名、默认币种、语言（中文 / English / 跟随系统）；退出登录。
14. **空状态 × 3**：新账本首页、没有交易的列表、没有导入记录。
15. **深色模式**：把 1、3、4 三屏各出一张深色版。

## 3. 交付提示词（最后一条）

请把这套设计整理成可以直接交给开发的交付物：
1. `tokens.json`：按 §1 的 token 名称，`light` 和 `dark` 两组，颜色用十六进制，字号 / 间距 / 圆角用像素数字，字体给字族名和回退栈。
2. `components.md`：每个组件的尺寸、内边距、边框、字号、各状态的 token 引用（引用 token 名，不写色值）。
3. 每个屏幕导出 PNG（375 和 1440 各一张），文件名用屏幕编号，如 `01-home-m.png` / `01-home-d.png`。
4. 一段"实现注意事项"：哪些效果在 React Native 上要换写法。

---

## 4. 交回 Claude Code 的方式

设计在 Claude Design 的普通项目「设计方案反馈」里进行（2026-09-10 决定；同步工具只能读"设计系统"类型的项目，所以不走同步）。做完后：

1. 用 §3 让 Claude Design 整理出 `tokens.json`、`components.md`、各屏 PNG 和实现注意事项。
2. 放到仓库 `docs/target-design/mockups/`（目录结构见那里的 README），或用项目里的"Send to Claude Code"发过来。
3. 告诉 Claude Code 一声，它会据此写 `frontend/src/theme/tokens.ts` 和组件库，并把 04 章 §6 更新成最终稿，04-D-13（视觉方向）随之关闭。
