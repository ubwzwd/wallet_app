状态用四个词：**已改**（要求完全落地）、**部分**（落了一半或留了矛盾文案）、**未改**（原样保留）、**改错**（改了但改反或改出新矛盾）。

六条全局规则（对每屏都查）：

1. 交易只有四种（支出 / 收入 / 退款 / 转账）；转账无商户无分类，标题写「A → B」或「对方：X」。

3. 界面上不出现「App」「客户端 iOS」（本版本只有网页端）。
4. 账户类型只有储蓄卡 / 信用卡 / 现金 / 其他，没有「储蓄」「Savings」。
5. 一级判据与二级样例以 `00-decisions.md` §1.3 的冻结分类表为准。
6. 导入只收 CSV，首行 `# version: 2026-09-10`，第二行是固定 11 列表头。
