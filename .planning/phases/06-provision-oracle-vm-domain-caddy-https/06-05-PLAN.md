<objective>
Operator-driven execution of RUNBOOK.md §0–§10 inclusive: provision the Oracle A1.Flex VM, register the Cloudflare Registrar domain, harden the VM per SEC-02 baseline, install Docker, set up the DNS A record + dig propagation gate, author the VM's `.env` with the **LE staging** CADDY_ACME_CA, deploy the stack with `docker compose up -d --wait`, and verify the staging cert is issued (incognito browser only — Pitfall 7).

This is Commit A of the D-05 two-commit pattern. The LE prod flip lives in Plan 06 (next plan).

Purpose: Bring the wallet app online publicly with a staging cert as a deliberate, reversible, low-rate-limit-cost first step. Confirms domain/DNS/firewall/ACME-flow correctness BEFORE consuming LE prod issuance budget.

Output: 1 commit-A evidence log file + 1 SC4 evidence log file + 1 nmap scan text file in `infra/runbook-evidence/`. The VM is live with a staging cert.
</objective>
