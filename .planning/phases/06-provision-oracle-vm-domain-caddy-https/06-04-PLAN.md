    ### §8. Wait for DNS propagation — D-04 HARD PREREQUISITE
    **CRITICAL CALLOUT (Pitfall 2)**: DO NOT proceed to §9 until `dig` confirms the A record from a public resolver. Skipping this gate means Caddy's first start will fail HTTP-01 challenge → LE staging endpoint records a failed validation. Even staging-cert validations consume rate-limit budget.

    From your laptop (NOT the VM — use a public resolver to avoid local DNS cache):
    ```bash
    DOMAIN="<your-domain>"
    EXPECTED_IP="<vm-ip>"

    while true; do
      ACTUAL=$(dig @1.1.1.1 "$DOMAIN" +short | head -1)
      if [ "$ACTUAL" = "$EXPECTED_IP" ]; then
        echo "DNS propagated: $DOMAIN -> $EXPECTED_IP"
        break
      fi
      echo "Waiting for DNS... got [$ACTUAL] expected [$EXPECTED_IP]"
      sleep 10
    done
    ```

    Cross-check from a second public resolver:
    ```bash
    dig @8.8.8.8 "$DOMAIN" +short
    # Must also return $EXPECTED_IP
    ```
