Wire the Workbox-generated service worker into the build pipeline and ship the React-Native-Web "Update available" toast that lets users opt in to a SW upgrade without manual cache clearing. This plan owns PWA-04 end-to-end: the SW source-of-truth (`workbox-config.cjs`), the web-only registration code path, the update hook, and the toast component.

| Boundary | Description |
|----------|-------------|
| Browser ↔ Service Worker | SW intercepts every fetch request on the origin; a misconfigured cache could serve another user's data |
| Service Worker ↔ Cache Storage | CacheFirst entries can persist across user sessions on a shared device |
| Build pipeline ↔ workbox-cli | A compromised Workbox could inject arbitrary JS into the emitted sw.js (mitigated by 05-01's package legitimacy gate) |
